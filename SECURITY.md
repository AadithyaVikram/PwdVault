# Security status

PwdVault is a development MVP and has not received independent security review. See [production-readiness evidence and open gates](docs/PRODUCTION_READINESS.md).

Use synthetic credentials for evaluation until the open security, recovery, signing, and clean-machine checks are completed.

For a suspected vulnerability, contact the repository maintainer privately through GitHub before posting sensitive exploit details publicly. Do not attach real vaults, master passphrases, stored passwords, signing credentials, or memory dumps to public issues. This policy is not a promise of an audited or supported production release.
